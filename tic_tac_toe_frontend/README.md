# Tic Tac Toe — React Frontend (Ocean Professional)

Modern, minimalist Tic Tac Toe game with a centered single-page layout and Ocean Professional theme (blue & amber).

## Features
- Local multiplayer — Players X and O alternate turns
- Clear status indicator with current turn, winner, or draw
- Elegant board with subtle shadows, rounded corners, and smooth transitions
- Reset button to start a new game
- Lightweight: pure React + CSS, no UI frameworks

## Getting Started
- npm install — Install dependencies
- npm start — Run in development mode at http://localhost:3000
- npm test — Run tests
- npm run build — Build production bundle

## Theme
- Primary: #2563EB (blue)
- Secondary/Success: #F59E0B (amber)
- Error: #EF4444 (red)
- Background: #f9fafb
- Surface: #ffffff
- Text: #111827

## Structure
- src/App.js — Shell layout and page structure
- src/components/TicTacToe.js — Game logic and UI (board, squares, status, reset)
- src/index.css — Global theme and component styles
- src/App.css — Minimal helpers
